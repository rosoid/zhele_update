# zhele — обновления

Здесь только готовые сборки zhele — среды и языка «желе» для нейросетей: установщик `zhele_setup.exe`,
подписанный автором пакет обновления (`.zhu`) и `version.json`. Исходников здесь нет.

Установленная программа сама проверяет этот адрес и ставит новую версию при следующем запуске; пакет без подписи
автора она не примет.
